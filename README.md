# Prosper Doko — Multilingual Technical Portfolio

Static GitHub Pages portfolio with automatic browser-language detection.

Live URL: <https://shadonet.github.io/>

## Language behavior

- French (`fr-*`) browsers open the portfolio in French.
- English (`en-*`) browsers open it in English.
- Other browser languages fall back to English.
- A visible FR / EN selector lets the visitor switch manually.
- The manual choice is saved in `localStorage` and reused on future visits.
- The CV download button follows the active language automatically.

## Deploy to GitHub Pages

1. Push the files to the root of your GitHub repository.
2. Go to `Settings` → `Pages`.
3. Choose `Deploy from a branch`.
4. Select `main` and `/ (root)`.
5. Save.

No build step is required.
